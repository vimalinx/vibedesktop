# Support

Use [GitHub Discussions](https://github.com/vimalinx/vibedesktop/discussions)
for installation and usage questions. Use
[GitHub Issues](https://github.com/vimalinx/vibedesktop/issues) for reproducible
bugs and feature requests.

Before opening a report, include the Vibe Desktop version, Linux distribution,
Node.js version, relevant `vibedesktop status` or `vibed health` output, and the
smallest reproduction you can provide. Remove tokens, credentials, private
paths, and personal data from logs.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public
issue. Community support is best-effort; the project does not promise a service
level or private product support.
