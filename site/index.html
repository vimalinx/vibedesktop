THE PROBLEM IT SOLVES

No more terminals, ports, and half-running apps.

不用再开一堆终端、记一堆端口，也不会再出现「前端在跑、后端挂了」。

01

Import a folder, get an app

Detects web/ + server/ style layouts and common frameworks, or follows the project's own .vibedesktop/app.json.

02

Start and stop as one

All services run in one supervised group. If one dies, the whole app restarts with back-off instead of half-running.

03

Verified, reversible installs

An install only counts once the page answers. A failed install or update is rolled back; your app data is kept.

04

Nothing hidden

Each app gets a readable run.sh, per-service logs, and live CPU and memory. Your source tree is never modified.

LINUX · GIT · ONE COMMAND

Install the whole desktop.

The installer picks the first free port from 3000–3010, brings a pinned Node.js when needed, and creates user services. Then run vibedesktop open.

Terminallatest release
